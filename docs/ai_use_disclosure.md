# AI-use disclosure

Drafts for the manuscript and the thesis book. Both are meant to be factually
exact: they neither overstate nor understate the human contribution. Adapt the
wording to each venue's policy; keep the facts.

What the record shows, for reference when adapting the text:

- **Tool.** Claude Code (Anthropic), an AI coding assistant, running Claude Opus
  models. Every commit it contributed to carries a `Co-Authored-By: Claude ...`
  trailer in the repository's git history, which is the complete, verifiable
  record of its involvement.
- **What the tool did.** It wrote the code of the experimental pipeline (data
  download and pinning, cleaning, split generation, feature extraction, the model
  heads, training, the encoder cache, the statistical analysis, and the generation
  of every table and figure) and the automated test suite. It drafted much of the
  protocol text (`docs/PROTOCOL.md`) and the other documents in `docs/` from the
  author's instructions. It also identified a number of methodological problems
  and proposed fixes (for example data leakage under a weak deduplication key, the
  capacity confound between heads, and a flaw in the first design of the
  permutation control).
- **What the author did.** The author set the research question and every design
  decision: each fix proposed by the tool was accepted, modified or rejected by the
  author, and the protocol records the decision and its justification. The author
  fixed the analysis plan before any experiment was run and interprets all results.
  The tool was explicitly instructed not to interpret results, and did not.
- **Why the numbers can be trusted independently of who typed the code.** No
  reported number is entered by hand: every table and figure is generated by code
  from the run logs. Every experimental run is deterministic, records the commit it
  ran from, and is reproducible bit for bit. An automated test suite enforces the
  no-leakage, parallel-data and model-specification rules, and the grid refuses to
  start unless the suite passes.

> its automated test suite, and drafted much of the accompanying documentation from
